## 6. 발견·수정한 문제
1. (Android 빌드) `Text.Title` 등 스타일의 암묵적 부모 `Text`가 없어 리소스 링크 실패 → 부모를 명시적으로 비움.
2. (Android 빌드) LevelView의 `min(Int, Float)` 타입 불일치 → Float로 통일.
3. 최신 Chrome에도 `DeviceOrientationEvent.requestPermission`이 있어 Android에서도 권한 버튼이 먼저 뜨던 문제 → 먼저 수신을 시도하고 1초간 값이 없을 때만 버튼 표시로 수정.
2. 센서 이벤트가 값이 바뀔 때만 오는 환경에서 필터가 수렴하지 않던 문제 → 필터를 화면 프레임 단위로 적용하도록 수정.
3. 평면 모드의 "회전각"이 의미 없는 값이던 문제 → "낮은 쪽 방향(0~360°)"으로 변경.
4. 점을 찍은 직후 큰 숫자가 0.0 cm로 바뀌던 문제 → 진행 중 거리와 "마지막 구간·합계"를 분리 표시.
5. WebGL 선 굵기 1px 제한으로 측정선이 잘 안 보이던 문제 → 얇은 원기둥 메시로 렌더링.
