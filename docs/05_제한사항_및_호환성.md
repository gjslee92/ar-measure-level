# 알려진 제한사항 및 호환성 안내

## 1. 플랫폼 호환성
| 환경 | 길이 측정(AR) | 수평기 | 기록·CSV | 오프라인 |
|---|---|---|---|---|
| Android APK (ARCore 지원 기기) | ✅ | ✅ | ✅ | ✅ |
| Android APK (ARCore 미지원 기기) | ❌ 안내 표시 | ✅ | ✅ | ✅ |
| 웹앱 · Android Chrome (ARCore 지원 기기) | ✅ | ✅ | ✅ | ✅ (첫 접속 후) |
| 웹앱 · Android 삼성 인터넷/기타 | 브라우저에 따라 다름 | ✅ 대부분 | ✅ | ✅ |
| 웹앱 · iPhone/iPad Safari | ❌ (Safari는 WebXR AR 미지원) | ✅ (권한 버튼 1회) | ✅ | ✅ |
| 웹앱 · PC 브라우저 | ❌ | ❌ (센서 없음) | ✅ | ✅ |

## 2. 웹앱과 APK의 차이
- **측정 사진**: APK는 카메라 영상 + 측정선을 항상 저장합니다. 웹앱은 브라우저 보안 정책상 AR 카메라 영상을 읽을 수 없는 경우가 많아, 그때는 **측정선·수치만 그린 이미지**를 저장하고 이미지 상단에 그 사실을 표시합니다.
- **정밀도**: 두 플랫폼 모두 ARCore를 쓰지만, APK는 평면 다각형 내부 여부를 직접 확인하고 조명 추정을 사용하므로 안내가 더 세밀합니다.
- **화면 방향**: APK는 세로 고정. 웹앱은 브라우저가 화면 회전을 막지 못할 수 있어, 회전 시 표시 방향을 자동 보정합니다.
- **저장 위치**: APK는 앱 내부 저장소, 웹앱은 해당 사이트의 브라우저 저장소. 서로 공유되지 않습니다.

## 3. 측정 정확도 관련
- 측정값은 **참고용**이며 줄자·레이저 측정기 수준의 정밀도를 보장하지 않습니다.
- ARCore 일반 오차: 1 m 안팎 거리에서 수 mm ~ 수 cm. 거리가 멀수록, 조명이 어두울수록, 무늬 없는 표면일수록 커집니다.
- 공중의 점(평면이 없는 곳)은 측정할 수 없습니다. 평면 위의 점만 찍을 수 있습니다.
- 수평기 정밀도는 기기 센서 품질에 좌우됩니다. 0.1° 단위로 표시하지만 실제 정확도는 보정 후 대략 0.1~0.3° 수준이 일반적입니다(기종별 차이, 실기기 미검증).
- 휴대폰 케이스·카메라 돌출부 때문에 모서리를 댈 때 기울어질 수 있습니다. 같은 상태로 2단계 보정하세요.

## 4. 데이터
- 로그인·동기화가 없으므로 **기기를 바꾸면 기록이 옮겨지지 않습니다.** CSV로 내보내 보관하세요.
- Android: 앱 삭제 시 기록·사진 삭제. 클라우드 백업에서도 제외되어 있습니다.
- 웹앱: 브라우저의 "인터넷 사용 기록/사이트 데이터 삭제", 시크릿 모드 종료 시 기록 삭제. 저장 공간이 부족하면 사진 없이 저장을 다시 시도합니다.

## 5. 이번 작업의 검증 한계
- 작업 환경에서 Google 저장소(dl.google.com, maven.google.com) 접속이 차단되어 **APK를 직접 빌드하지 못했습니다.** Android Studio 또는 GitHub Actions에서 빌드해야 하며, 첫 빌드 시 컴파일 오류가 나오면 오류 메시지를 알려주시면 수정하겠습니다.
- 실기기 테스트를 하지 못했습니다. `04_테스트_결과_보고서.md`의 실기기 확인 항목을 참고하세요.
- 라이브러리 버전(ARCore 1.46.0 등)은 작성 시점 기준이며, 더 새로운 버전으로 올려도 됩니다.
