## 2. AR 길이 측정 알고리즘
1. **평면 인식 후에만 측정 허용** — 화면 중앙에서 hit-test를 하고, 결과가 *추적 중인 평면의 다각형 내부*일 때만 유효(Android: `Plane.isPoseInPolygon`, 웹: WebXR hit-test 기본 대상 = plane). 유효한 결과가 **15프레임 연속**(약 0.25초)이어야 표적이 초록색이 되고 점을 찍을 수 있습니다.
2. **동일 좌표계** — 모든 점은 하나의 세션 월드 좌표계(웹: `local` 참조 공간)에 있습니다.
3. **앵커 고정** — 각 점은 Anchor로 만들어 매 프레임 앵커 위치로 갱신합니다. ARCore가 공간 지도를 보정하면 점도 함께 보정됩니다.
4. **거리** — 3차원 유클리드 거리 `√(Δx²+Δy²+Δz²)`. 서로 높이가 다른 두 점(바닥↔벽)도 직선거리로 계산합니다.
5. **연속 측정** — 점 목록을 "체인"으로 관리. 같은 체인의 이웃 점끼리 구간이 되고, "새 구간"은 새 체인을 시작합니다. 합계 = 모든 구간 합.
6. **측정 불가 상태에서 값 출력 금지** — 추적 상실·평면 없음이면 점 추가 버튼이 비활성화되고, 눌러도 안내만 하고 값을 만들지 않습니다.
7. **안내** — 추적 실패 사유(어두움/과도한 움직임/특징점 부족), 카메라 이동속도 0.6 m/s 초과 시 흔들림, 측정점이 3 m 초과 시 오차 경고, 장시간 평면 미발견 시 표면 안내.

## 3. 수평기 알고리즘
- 센서에서 **하늘 방향 단위벡터 u**(기기 좌표: x=오른쪽, y=화면 위, z=화면 바깥)를 구합니다.
  - Android: 중력 센서 값을 정규화
  - 웹: `beta/gamma`로부터 `u = (−cosβ·sinγ, sinβ, cosβ·cosγ)` — 짐벌락(β≈90°)에서도 연속
- **필터** — 벡터 지수이동평균(α: 약 0.35 / 보통 0.15 / 강 0.06), 화면 프레임마다 적용.
- **평면 모드**: 좌우 = atan2(−uₓ, u_z), 전후 = atan2(u_y, u_z), 총 기울기 = acos(u_z), 낮은 쪽 방향(0~360°).
- **세움 모드**: 회전각 φ = atan2(−uₓ, u_y) (0~360°, 시계방향 +). 가장 가까운 0/90/180/270°와의 차이가 오차. 0·180° 근처 = **수직 측정**, 90·270° 근처 = **수평 측정**. 앞뒤 기울기 = asin(u_z).
- **자동 모드**: |u_z| > 0.707이면 평면, 히스테리시스(0.62/0.78)로 경계에서 깜빡임 방지.
- **판정**: 기본 ≤0.5° 매우 정확 / ≤1.0° 거의 수평 / 초과 기울어짐 (사용자 변경 가능).
- **안정도**: 최근 30개 값 표준편차 < 0.08°일 때만 영점·보정 허용.
- **영점 보정**: 현재 원시값을 오프셋으로 저장(15° 초과는 거부).
- **2단계 보정**: 180° 돌려 두 번 잰 값의 평균 = 센서 바이어스 (r₁ = t + b, r₂ = −t + b → b = (r₁+r₂)/2). 바닥이 완전히 평평하지 않아도 정확합니다.
- **센서 중단 감지**: 3초간 값이 없으면 "수신 중단" 표시, 재수신 시 자동 복귀. 처음 2.5초간 값이 없으면 오류 안내.

## 4. 데이터
- 길이 기록: 합계(m), 단위, 구간 목록(각 구간 길이와 양 끝 3D 좌표), 사진, 메모, 생성 시각
- 각도 기록: 대표 각도, 모드, 축별 각도·방향, 회전각, 판정, 보정 여부, 고정 기준 대비 차이
- CSV 열: 번호, 날짜, 시간, 측정 종류, 측정값, 측정 단위, 세부 내용, 메모 / UTF-8 BOM, CRLF
- 외부 전송 없음: Android는 INTERNET 권한 미선언, 클라우드 백업 제외 설정. 웹앱은 외부 스크립트·폰트·분석도구 없음.
