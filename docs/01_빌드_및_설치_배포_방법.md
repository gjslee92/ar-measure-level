# 빌드 · 실행 · 설치 · 배포 방법

## 1. 모바일 웹앱

### 1-1. 구조
빌드 과정이 없는 순수 HTML/CSS/JavaScript 앱입니다. `webapp` 폴더 전체가 배포물입니다.

```
webapp/
├─ index.html              화면 구조
├─ css/app.css             디자인(다크/라이트)
├─ js/app.js               화면 전환·기록·설정
├─ js/level.js, levelmath.js  수평기
├─ js/ar.js                WebXR AR 길이 측정
├─ js/db.js                IndexedDB 기록 저장
├─ js/csv.js               CSV 내보내기(UTF-8 BOM)
├─ vendor/three.module.min.js  3D 렌더링(three.js r170, 로컬 포함 → 외부 접속 없음)
├─ sw.js, manifest.webmanifest  오프라인 실행·홈 화면 설치
└─ icons/
```

### 1-2. PC에서 실행해 보기
```bash
cd webapp
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```
PC에는 기울기 센서·AR이 없으므로 화면 확인용입니다.

### 1-3. 휴대폰에서 쓰려면 HTTPS 배포가 필수
카메라·센서·오프라인 기능은 **HTTPS 주소**에서만 동작합니다. 무료로 할 수 있는 방법:

**방법 A — GitHub Pages (권장, 자동)**
1. GitHub에 새 저장소를 만들고 이 프로젝트 폴더 전체를 올립니다.
2. 저장소 Settings › Pages › Source를 **GitHub Actions**로 선택합니다.
3. 올릴 때마다 `.github/workflows/build-apk.yml`이 웹앱을 자동 배포합니다. 주소: `https://<아이디>.github.io/<저장소이름>/`

**방법 B — Netlify Drop**
1. https://app.netlify.com/drop 에 `webapp` 폴더를 끌어다 놓습니다.
2. 표시되는 `https://….netlify.app` 주소로 접속합니다.

**방법 C — 사내 웹서버**
`webapp` 폴더를 HTTPS가 적용된 웹서버의 아무 경로에 복사합니다. 서버 측 프로그램은 필요 없습니다.

### 1-4. 홈 화면에 설치(앱처럼 사용)
- Android Chrome: 메뉴(⋮) › **홈 화면에 추가** 또는 **앱 설치**
- iPhone Safari: 공유 버튼 › **홈 화면에 추가**
한 번 접속하면 서비스워커가 파일을 저장하므로 이후 **인터넷 없이** 실행됩니다.

## 2. Android APK

### 2-1. 개발 환경
| 항목 | 버전 |
|---|---|
| Android Studio | Ladybug(2024.2) 이상 권장 |
| JDK | 17 (Android Studio 내장 JDK 사용 가능) |
| Gradle | 8.11.1 (wrapper 포함) |
| Android Gradle Plugin | 8.7.3 |
| Kotlin | 2.0.21 |
| compileSdk / targetSdk / minSdk | 35 / 35 / 24 (ARCore 최소 Android 7.0) |
| 주요 라이브러리 | ARCore 1.46.0, Room 2.6.1, Material 1.12.0 |

### 2-2. 방법 A — Android Studio로 빌드
1. Android Studio › **Open** › `android` 폴더 선택
2. Gradle 동기화가 끝날 때까지 기다립니다(첫 실행 시 라이브러리 다운로드, 인터넷 필요).
3. 메뉴 **Build › Build App Bundle(s) / APK(s) › Build APK(s)**
4. 완료 알림의 **locate** 클릭 → `android/app/build/outputs/apk/debug/app-debug.apk`

명령줄로는:
```bash
cd android
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
./gradlew testDebugUnitTest    # 단위 테스트
```

### 2-3. 방법 B — GitHub Actions로 자동 빌드 (PC에 아무것도 설치하지 않음)
1. 이 프로젝트 폴더 전체를 GitHub 저장소에 올립니다(`.github` 폴더 포함).
2. 저장소의 **Actions** 탭에서 `Build APK & Deploy Web App` 실행이 끝나기를 기다립니다(약 5~10분).
3. 실행 결과 화면 하단 **Artifacts › ARMeasureLevel-apk**를 내려받아 압축을 풀면 APK가 있습니다.
   - `app-debug.apk` : 바로 설치 가능
   - `app-release.apk` : 서명 키를 등록하지 않았다면 디버그 키로 서명되어 역시 설치 가능

### 2-4. 정식 서명(선택)
배포용 서명 키를 쓰려면 다음 환경변수를 설정하고 `./gradlew assembleRelease`를 실행합니다.
`ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`

### 2-5. 휴대폰에 APK 설치
1. APK 파일을 휴대폰으로 옮깁니다(USB, 카카오톡 나에게 보내기, 구글 드라이브 등).
2. 파일을 누르면 "출처를 알 수 없는 앱" 경고가 나옵니다 → **설정 › 이 출처 허용**을 켭니다.
3. **설치**를 누릅니다.
4. 첫 실행 시 로그인 없이 메인 화면이 열립니다. 길이 측정을 처음 누르면 **카메라 권한**을 요청하고, 필요하면 **Google Play 서비스 AR(ARCore)** 설치 화면으로 안내합니다.

PC에 USB로 연결한 경우: `adb install -r app-debug.apk`

### 2-6. ARCore 지원 기기 확인
Google의 ARCore 지원 기기 목록: https://developers.google.com/ar/devices
목록에 없는 기기에서도 앱은 설치되며 **수평기·기록 기능은 정상 동작**하고, 길이 측정만 "지원하지 않음"으로 안내됩니다.
