# 사용자 매뉴얼

## 시작하기
앱(또는 웹 주소)을 열면 로그인 없이 바로 **메인 화면**이 나옵니다.

| 메뉴 | 하는 일 |
|---|---|
| 길이 측정 | 카메라로 두 점 사이 거리를 잽니다 |
| 디지털 수평기 | 수평·수직·기울기 각도를 확인합니다 |
| 측정 기록 | 저장한 측정값을 보고, 지우고, CSV로 내보냅니다 |
| 설정 | 단위·소수점·수평 판정 기준·진동·테마 등을 바꿉니다 |

메인 화면 아래에 이 기기에서 AR·센서를 쓸 수 있는지가 표시됩니다.

---

## 길이 측정 (AR)

1. **길이 측정**을 누르고(웹앱은 **AR 측정 시작**), 카메라 권한을 허용합니다.
2. 밝은 곳에서 무늬가 있는 바닥·책상·벽을 비추고 휴대폰을 **천천히 좌우로** 움직입니다.
3. 화면 가운데 표적(원)이 **초록색**이 되면 측정할 수 있습니다.
4. 표적을 **시작점**에 맞추고 화면을 탭(또는 아래 흰 원 버튼)합니다.
5. 표적을 **종료점**으로 옮기면 거리가 실시간으로 표시되고, 탭하면 확정됩니다.
6. 계속 탭하면 이어지는 구간이 **연속 측정**됩니다. 떨어진 곳을 따로 재려면 **새 구간**을 누릅니다.

| 버튼 | 기능 |
|---|---|
| 단위 | mm → cm → m 순서로 바꿉니다 |
| 되돌리기 | 마지막 점을 지웁니다 |
| 새 구간 | 다음 탭부터 별도 구간을 시작합니다 |
| 초기화 | 모든 점을 지웁니다 |
| 저장 | 측정 구간·합계를 기록에 저장합니다(설정에서 켜면 사진도 저장) |

화면 아래 큰 숫자는 지금 재고 있는 거리, 그 밑 줄은 "마지막 구간 · 구간 수 · 합계"입니다.

### 정확하게 재는 요령
- 대상에 **1~2 m 이내**로 다가가서 재세요. 3 m를 넘으면 경고가 나옵니다.
- 흰 벽, 유리, 거울, 광택 있는 바닥은 인식이 어렵습니다.
- 점을 찍을 때는 휴대폰을 멈춘 상태로 탭하세요. "카메라가 흔들립니다" 안내가 나오면 천천히 움직이세요.
- 같은 거리를 2~3번 재서 비교하면 오차를 줄일 수 있습니다.
- 측정값은 참고용이며 줄자·레이저 거리측정기 수준의 정밀도를 보장하지 않습니다.

### 안내 메시지
| 메시지 | 원인과 해결 |
|---|---|
| 평면을 찾는 중… | 아직 바닥/벽을 인식하지 못함 → 천천히 움직이며 무늬 있는 표면 비추기 |
| 조명이 어둡습니다 | 조명 켜기 |
| 표면 특징점이 부족합니다 | 무늬 있는 곳 비추기, 너무 가깝지 않게 |
| 표적이 평면을 벗어났습니다 | 측정할 표면으로 다시 표적 맞추기 |
| 이 기기는 ARCore를 지원하지 않습니다 | 길이 측정 불가, 수평기는 사용 가능 |
| iPhone Safari … 웹 AR 미지원 | 웹앱에서 AR 불가 → iPhone 기본 "측정" 앱 이용 |

## 디지털 수평기

상단에서 모드를 고릅니다.

| 모드 | 사용법 | 표시 |
|---|---|---|
| 자동 | 놓는 방식에 따라 자동 전환 | — |
| 평면(버블) | 휴대폰을 화면이 위로 오게 눕혀 놓기 | 원형 버블, 좌우·전후 기울기, 낮은 쪽 방향 |
| 수평·수직(세움) | 휴대폰 모서리를 대상에 세워 대기 | 가로로 세우면 **수평 오차**, 세로로 세우면 **수직 오차** |

- 큰 숫자: 현재 기울기(°). 버블은 **높은 쪽**으로 이동합니다.
- 색: **초록** 0.5° 이하(매우 정확) · **노랑** 1.0° 이하(거의 수평) · **빨강** 기울어짐 — 기준은 설정에서 변경
- "오른쪽이 낮음" 등의 방향 문구로 어느 쪽을 올려야 할지 알려줍니다.
- 회전각: 휴대폰이 화면 평면에서 몇 도 돌아갔는지 0~360°로 표시합니다.

### 영점 보정
- **영점 설정**: 확실히 평평한 곳에 놓고 누르면 현재 상태를 0°로 맞춥니다.
- **정밀 보정(2단계)**: 센서 자체 오차까지 없앱니다. ① 놓고 [측정 1] → ② 같은 자리에서 **180° 돌려** 놓고 [측정 2]. 평평한 곳이 확실하지 않을 때 이 방법이 더 정확합니다.
- **보정 초기화**: 보정값을 지웁니다.
- 휴대폰 케이스를 바꾸면 다시 보정하세요.

### 각도 고정
설치 작업 중 기준 각도와 비교할 때 사용합니다. **각도 고정**을 누르면 지금 각도가 기준이 되고, 이후 기준과의 **차이**가 표시됩니다. 다시 누르면 해제됩니다.
(예: 전자칠판 왼쪽 브래킷에서 고정 → 오른쪽 브래킷에 대고 차이가 0°가 되도록 조정)

## 측정 기록
- 저장한 길이·각도가 최신순으로 표시됩니다. **전체 / 길이 / 각도**로 걸러 볼 수 있습니다.
- 항목을 누르면 상세(구간별 길이, 각도 세부값, 사진)가 보이고 **메모**를 달 수 있습니다.
- 휴지통 버튼: 개별 삭제 / **전체 기록 삭제**: 모두 삭제(되돌릴 수 없음)
- **CSV 내보내기**: 날짜·시간·측정 종류·측정값·단위·세부 내용·메모가 담긴 파일. 엑셀에서 한글이 깨지지 않습니다.
- 사진(Android): 상세 화면에서 **갤러리에 저장** 또는 **공유**

> 기록은 이 기기에만 저장됩니다. 앱을 삭제하거나(Android) 브라우저의 사이트 데이터를 지우면(웹앱) 기록도 삭제됩니다. 중요한 기록은 CSV로 내보내 보관하세요.

## 설정
| 항목 | 설명 |
|---|---|
| 기본 단위 / 소수점 자릿수 | 길이 표시 형식 (mm·cm·m, 0~3자리) |
| 길이 저장 시 사진도 저장 | 끄면 수치만 저장 |
| '매우 정확' / '거의 수평' 기준 | 수평 판정 색상 기준(°) |
| 센서 필터 | 강하게 = 숫자가 덜 흔들림 · 약하게 = 반응이 빠름 |
| 진동 / 소리 | 수평에 도달하는 순간 알림 |
| 테마 | 다크 · 라이트 · 시스템 설정 |
| 센서 보정값 초기화 · 기록 전체 삭제 · 앱 정보 | — |
